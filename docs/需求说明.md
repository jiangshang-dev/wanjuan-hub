
目录说明：
wanjuan-views:论坛的用户前台
wanjuan-back:论坛的管理员后台
sql:数据库脚本

技术架构：
- 前端：Vue3 + Ant Design Vue+ JavaScript
- 后端：Spring Boot4 + Mybatis-Plus + Redis + Spring Security
- 数据库：MySQL
- 存储：RustFS
- 消息队列：RabbitMQ

需求要求：
1、论坛和博客用户发布博客和论坛、跟帖、评论回复时先阿里云内容审核，审核通过后才能发布（MQ异步处理）
2、支付宝支付、微信支付 API v3 支持
3、论坛前台需求：
用户登录、密码重置、手机号绑定、邮箱绑定、个人中心、用户信息管理
登录用验证码登录、会员中心、用户等级；
新用户登录默认昵称，用户可以在个人中心修改昵称、头像、个性签名、出生日期等；

目前的前台网站的不对，类似掘金、csdn、瑞客论坛[https://www.ruike1.com] 、吾爱破解论坛类似，应该是如下需求：
首页包括博客、论坛门户，展示分类、文章、论坛等内容，点赞和评论数量，
用户发布论坛和博客奖励积分，积分可以在个人中心查看和使用。
获取资源n种方式：
1、积分兑换资源
2、购买会员后每日一定量获取资源，在后台可以配置
3、免费资源，无需积分和会员即可查看
资源网盘链接可以在博客文章里面，也可以在论坛里面查看。
每日签到可以获取一定的积分奖励，在后台可以配置。
支持连续签到可以获取更多的积分奖励，在后台可以配置。
连续签到中断后，需要重新开始连续签到。
钱包功能。

博客和论坛都支持点赞、点踩、评论点赞、点踩。
显示点赞和点踩的数量、是否支持要用户点踩、点赞可以博主用户在个人中心设置开关，默认是开启的。
特殊日子可以支持管理员设置网站前台整体灰色主题，例如：特殊日子可以设置为灰色主题，用户在特殊日子不能点赞、点踩、评论点赞、点踩。

免费资源不给发帖人返现；
会员资源和积分资源给发帖人返佣金奖励，可以在余额钱包中提现，提现需要指定支付宝账号，提现后审核中，后台运营人员转账到指定的支付宝账号，提现成功后，用户可以在个人中心、钱包中查看提现记录。

管理运营人员在后台支持设置前台的背景音乐开关，后台设置自动播放或手动播放、显示或隐藏音乐播放器，
前台打开后自动播放背景音乐、显示或隐藏音乐播放器。

前台支持意见反馈，用户可以在个人中心提交意见反馈，管理员可以在后台查看和回复。
前台首页搜索功能，支持搜索博客、论坛，用es搜索。
用户还是管理员发布博客、论坛时，审核通过状态后使用mq异步处理同步到es，mysql和es异步同步数据。

前台用户收到消息要有通知提醒消息，如点赞、点踩、评论、@、积分奖励、提现、审核通过等诸多情况。

论坛博客管理后台需求：
写日志注解，记录用户操作日志，包括IP地址、操作时间、操作人、操作内容、地点等
封装获取当前登录用户的ID方法
后台管理的基础功能必须都要有
菜单管理、权限、精确到按钮控制
