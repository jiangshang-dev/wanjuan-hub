
目录说明：
wanjuan-views:论坛的用户前台
wanjuan-back:论坛的管理员后台
sql:数据库脚本

技术架构：
- 前端：Vue3 + Ant Design Vue+ JavaScript
- 后端：Spring Boot4 + Mybatis-Plus + Redis + Spring Security
- 数据库：MySQL
- 存储：RustFS
- 消息队列：RabbitMQ

需求要求：
1、论坛和博客用户发布博客和论坛、跟帖、评论回复时先阿里云内容审核，审核通过后才能发布（MQ异步处理）
2、支付宝支付、微信支付 API v3 支持
3、论坛前台需求：
用户登录、密码重置、手机号绑定、邮箱绑定、个人中心、用户信息管理
登录用验证码登录、会员中心、用户等级；
新用户登录默认昵称，用户可以在个人中心修改昵称、头像、个性签名、出生日期等；

论坛博客管理后台需求：
写日志注解，记录用户操作日志，包括IP地址、操作时间、操作人、操作内容、地点等
封装获取当前登录用户的ID方法
后台管理的基础功能必须都要有
菜单管理、权限、精确到按钮控制
